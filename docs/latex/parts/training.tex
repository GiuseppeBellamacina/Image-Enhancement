\section{Training}
\label{sec:training}

\subsection{Training Pipeline}

The training loop is implemented in \texttt{trainer.py} and supports all architectures through a unified interface. The function \texttt{run\_training} orchestrates the entire process: learning rate warmup, train/validation alternation, checkpointing, early stopping, and logging.

\subsubsection{Mixed Precision (AMP)}
All experiments (except the Denoising Autoencoder) use PyTorch Automatic Mixed Precision~\cite{amp}: forward pass operations execute in FP16 via \texttt{torch.autocast}, while the loss is always computed in FP32 for numerical stability. A \texttt{GradScaler} manages gradient rescaling. Validation is \textbf{always} performed in full precision, regardless of AMP settings, to avoid instabilities caused by BatchNorm in eval mode interacting with FP16.

\subsubsection{Learning Rate Warmup}
The first \texttt{warmup\_epochs} (typically 5--8) use linear warmup of the learning rate from a small initial value to the target rate. The main scheduler (CosineAnnealing or StepLR) activates only after warmup completion.

\subsubsection{Gradient Clipping}
Gradients are clipped via \texttt{clip\_grad\_norm\_} with a configurable maximum norm (typically 0.5--1.0). Under AMP, gradients are first unscaled by the \texttt{GradScaler} before clipping.

\subsubsection{Early Stopping}
The patience counter increments only at validation epochs where the validation loss does not improve. This allows configuring validation at intervals (\eg, every 2 epochs) without penalizing the patience count.

\subsubsection{OOM Error Handling}
On Out-of-Memory errors during training, the system: (1) saves an emergency checkpoint, (2) frees CUDA memory, and (3) prints diagnostic suggestions (reduce batch/patch size, enable AMP).

\subsection{Pix2Pix Training}

Pix2Pix follows the GAN paradigm with alternating discriminator and generator updates.

\subsubsection{Discriminator Training}
The discriminator receives image pairs (conditional + target):
\begin{itemize}
    \item \textbf{Real pairs:} $(x_{\text{degraded}}, x_{\text{clean}}) \to$ label 1
    \item \textbf{Fake pairs:} $(x_{\text{degraded}}, G(x_{\text{degraded}})) \to$ label 0
\end{itemize}
\begin{equation}
\mathcal{L}_D = \tfrac{1}{2}\left(\text{BCE}(D(x, y_{\text{real}}), 1) + \text{BCE}(D(x, y_{\text{fake}}), 0)\right)
\end{equation}

\subsubsection{Generator Training}
The generator loss combines adversarial and reconstruction components:
\begin{equation}
\mathcal{L}_G = \text{BCE}(D(x, G(x)), 1) + \lambda_{\text{L1}} \cdot \mathcal{L}_{\text{recon}}(G(x), y)
\end{equation}
where $\lambda_{\text{L1}} = 150$ and the reconstruction loss is the Combined Loss (L1 + SSIM). The high $\lambda_{\text{L1}}$ balances the adversarial component, which tends to dominate in early training phases.

\subsubsection{Noise Diagnostics}
In residual learning mode, statistics on predicted noise are monitored: mean, standard deviation, maximum value, outlier percentage (values exceeding the clamp threshold), and percentage of clipped output pixels.

\subsection{Implementation Notes}

\begin{itemize}
    \item \textbf{Optimizers:} UNet variants use AdamW ($\text{weight\_decay} = 10^{-5}$). DnCNN uses Adam with \textbf{no weight decay} (found empirically beneficial). RIDNet uses Adam ($\text{weight\_decay} = 10^{-4}$). Pix2Pix uses Adam with $\beta_1 = 0.5$.
    
    \item \textbf{Schedulers:} CosineAnnealingLR for most models; StepLR (step=1, $\gamma = 0.96$) for DnCNN; no scheduler for Pix2Pix generator.
    
    \item \textbf{Attention UNet bottleneck variants:} Use GroupNorm instead of BatchNorm, shallower perceptual layers (\texttt{relu1\_2} + \texttt{relu2\_2}), and reduced perceptual weight ($\gamma = 0.05$).
    
    \item \textbf{RIDNet specifics:} 8 EAB blocks with \texttt{residual\_scale} = 0.1, 96 feature channels (vs.\ 64 default), and stricter gradient clipping (norm = 0.5).
    
    \item \textbf{Dithering experiments:} Two additional experiments were conducted with 2-bit random dithering using the base UNet (both bilinear and transposed convolution variants).
\end{itemize}
