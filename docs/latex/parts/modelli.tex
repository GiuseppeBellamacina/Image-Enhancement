\section{Model Architectures}
\label{sec:models}

This section describes the architectures implemented. All models operate on RGB images normalized to $[-1, 1]$ and produce output in the same range. Two paradigms are distinguished: \textbf{direct prediction} of the clean image and \textbf{residual learning}, where the model predicts the noise to be subtracted from the input.

% ============================================================
\subsection{UNet}
\label{subsec:unet}

\textit{Developed by: Giuseppe Bellamacina}

\medskip

The UNet~\cite{unet} is an encoder-decoder architecture with skip connections, originally proposed for biomedical segmentation and adapted here to image restoration. The model learns a direct mapping from the degraded image to the clean one.

\subsubsection{Architecture}
The encoder consists of 4 downsampling stages, each comprising a \texttt{DoubleConv} block (two $3\!\times\!3$ convolutions with BatchNorm and ReLU) followed by $2\!\times\!2$ MaxPool:
\begin{equation}
\texttt{inc}(3 \!\to\! 64) \!\to\! \texttt{d}_1(64 \!\to\! 128) \!\to\! \texttt{d}_2(128 \!\to\! 256) \!\to\! \texttt{d}_3(256 \!\to\! 512) \!\to\! \texttt{d}_4(512 \!\to\! 1024)
\end{equation}

The decoder reconstructs spatial resolution via upsampling. Two modes are supported:
\begin{itemize}
    \item \textbf{Bilinear:} \texttt{nn.Upsample(scale\_factor=2, mode=`bilinear')} followed by \texttt{DoubleConv}.
    \item \textbf{Transposed Convolution:} \texttt{ConvTranspose2d(kernel=2, stride=2)}.
\end{itemize}

At each decoder level, encoder features are concatenated via skip connections. The final output is a $1\!\times\!1$ convolution mapping from 64 to 3 channels, without activation.

% ============================================================
\subsection{UNet Residual}
\label{subsec:unet-residual}

\textit{Developed by: Giuseppe Bellamacina}

\medskip

The UNet Residual shares the same encoder-decoder architecture as the base UNet, with a fundamental difference in the learning paradigm: the model predicts the \textbf{noise} present in the image rather than the clean image. The denoised output is obtained by subtraction:
\begin{equation}
\hat{x}_{\text{clean}} = x_{\text{noisy}} - f_\theta(x_{\text{noisy}})
\end{equation}
where $f_\theta$ is the network predicting the noise component.

\subsubsection{Anti-Checkerboard}
In the transposed convolution variant, the kernel size was increased from $2\!\times\!2$ to $4\!\times\!4$ with \texttt{padding=1}, ensuring more uniform coverage of output pixels and eliminating the checkerboard artifacts typical of standard deconvolution.

\subsection{Attention UNet}
\label{subsec:attention-unet}

\textit{Developed by: Giuseppe Bellamacina}

\medskip

The Attention UNet extends the UNet with \textit{attention gates}~\cite{attentiongate} in the skip connections, allowing the decoder to focus on the most relevant regions of encoder features.

\subsubsection{Attention Gate}
The attention gate computes a spatial attention map from the gating signal $g$ (from the lower decoder level) and the skip signal $x$ (from the encoder):
\begin{equation}
\alpha = \sigma\!\left(\psi\!\left(\text{ReLU}(W_g \cdot g + W_x \cdot x)\right)\right)
\end{equation}
where $W_g$ and $W_x$ are $1\!\times\!1$ convolutions with normalization, $\psi$ is a $1\!\times\!1$ convolution reducing to a single channel, and $\sigma$ is the sigmoid function. Skip features are modulated element-wise: $\hat{x} = \alpha \odot x$.

\subsubsection{Attention Levels}
Two configurations are supported:
\begin{itemize}
    \item \texttt{``bottleneck''}: attention gate applied only to the first decoder level.
    \item \texttt{``all''}: attention gates applied at all decoder levels.
\end{itemize}

\subsubsection{Normalization}
Both \texttt{BatchNorm2d} and \texttt{GroupNorm} (with $\min(8, C)$ groups) are supported, selectable via the \texttt{norm} parameter.

\subsubsection{Adaptive Blending}
An optional blending mechanism moderates model intervention based on estimated noise intensity. If a \texttt{noise\_sigma} value is provided at inference:
\begin{equation}
\alpha = \min\!\left(\frac{\sigma_{\text{noise}}}{\sigma_{\text{trained}}},\; 1.0\right), \quad
\text{output} = \alpha \cdot x_{\text{input}} + (1 - \alpha) \cdot x_{\text{denoised}}
\end{equation}

\subsection{DnCNN}
\label{subsec:dncnn}

\textit{Developed by: Salvo Iurato}

\medskip

DnCNN~\cite{dncnn} (\textit{Denoising Convolutional Neural Network}) is a purely sequential architecture exploiting residual learning. Unlike encoder-decoder architectures, it uses no downsampling or skip connections.

\subsubsection{Architecture}
The network consists of $D$ convolutional layers (17 in the best configuration):
\begin{enumerate}
    \item \textbf{First layer:} \texttt{Conv2d($3 \!\to\! F$, $3\!\times\!3$)} + ReLU (no BatchNorm).
    \item \textbf{Layers 2 to $D\!-\!1$:} \texttt{Conv2d($F \!\to\! F$, $3\!\times\!3$)} + BatchNorm + ReLU.
    \item \textbf{Last layer:} \texttt{Conv2d($F \!\to\! 3$, $3\!\times\!3$)} (no BatchNorm or activation).
\end{enumerate}

The predicted noise is subtracted from the input: $\hat{x}_{\text{clean}} = x_{\text{noisy}} - f_\theta(x_{\text{noisy}})$. Output is clamped to $[-1, 1]$ at inference. Weights are initialized with Kaiming normal for convolutions and constants (1/0) for BatchNorm.

\subsection{Denoising Autoencoder}
\label{subsec:denoising-autoencoder}

\textit{Developed by: Mattia Campanella}

\medskip

The Denoising Autoencoder is an encoder-decoder architecture \textbf{without skip connections}, designed as a baseline for comparison with more advanced architectures.

\subsubsection{Architecture}
The \textbf{encoder} performs 4 downsampling stages via strided convolutions ($3\!\times\!3$, \texttt{stride=2}), each followed by BatchNorm and LeakyReLU(0.2):
\begin{equation}
3 \xrightarrow{\text{s2}} 128 \xrightarrow{\text{s2}} 64 \xrightarrow{\text{s2}} 32 \xrightarrow{\text{s2}} 16 \text{ (spatial)} 
\end{equation}

The \textbf{decoder} reconstructs resolution via \texttt{Upsample(bilinear)} + \texttt{Conv2d($3\!\times\!3$)} at each stage, with BatchNorm and LeakyReLU, followed by a final Tanh activation producing output in $[-1, 1]$.

The absence of skip connections forces the bottleneck to encode all information necessary for reconstruction, making the model more ``lossy'' but simpler, and serving as a lower bound for architectures with skip connections.

\subsection{RIDNet}
\label{subsec:ridnet}

\textit{Developed by: Salvo Iurato}

\medskip

RIDNet~\cite{ridnet} (\textit{Real Image Denoising Network}) combines dilated convolutions and channel attention~\cite{se} to capture multi-scale information without pooling operations.

\subsubsection{Enhancement Attention Block (EAB)}
The fundamental building block consists of:
\begin{enumerate}
    \item Three convolutions with increasing dilation ($d = 1, 2, 3$), each followed by BatchNorm and ReLU, expanding the receptive field without reducing spatial resolution.
    \item A \texttt{ChannelAttention} module (Squeeze-and-Excitation): Global Average Pooling $\to$ Conv $1\!\times\!1$ ($C \!\to\! C/r$) $\to$ ReLU $\to$ Conv $1\!\times\!1$ ($C/r \!\to\! C$) $\to$ Sigmoid, with reduction factor $r = 16$.
    \item A local residual connection with scaling factor:
\end{enumerate}
\begin{equation}
\text{EAB}(x) = x + s \cdot \text{CA}(\text{dilated\_branch}(x))
\end{equation}
where $s$ is the \texttt{residual\_scale} (0.1 in our best experiments).

\subsubsection{Full Architecture}
\begin{enumerate}
    \item \textbf{Feature extraction:} \texttt{Conv2d($3 \!\to\! F$, $3\!\times\!3$)} + ReLU.
    \item \textbf{Enhancement:} Sequence of $N$ EAB blocks ($N = 8$ in best config).
    \item \textbf{Reconstruction:} \texttt{Conv2d($F \!\to\! 3$, $3\!\times\!3$)} predicting noise.
    \item \textbf{Global residual:} $\hat{x} = x - f_\theta(x)$.
\end{enumerate}
Output is clamped to $[-1, 1]$ at inference.

\subsection{Pix2Pix}
\label{subsec:pix2pix}

\textit{Developed by: Daniele Barbagallo}

\medskip

Pix2Pix~\cite{pix2pix} is an image-to-image translation framework based on conditional GANs. The system comprises a \textbf{generator} and a \textbf{discriminator} trained adversarially.

\subsubsection{Generator}
The generator has a UNet-like architecture with 7 downsampling levels, designed for $256\!\times\!256$ inputs.

\textbf{Encoder} (6 layers + bottleneck): Each layer uses \texttt{Conv2d($4\!\times\!4$, stride=2)} + BatchNorm + LeakyReLU(0.2). The first layer omits BatchNorm.

\textbf{Decoder} (6 layers + final): \texttt{ConvTranspose2d($4\!\times\!4$, stride=2)} + BatchNorm + ReLU, with Dropout(0.5) in the first 3 layers. Skip connections via concatenation with corresponding encoder features. The final layer produces 3 channels with Tanh activation (or without, for residual learning).

\subsubsection{PatchGAN Discriminator}
The discriminator operates on local image patches, classifying $70\!\times\!70$ regions as real or generated. Input is the concatenation of the conditional image (degraded) and target/generated image (6 channels total). The architecture consists of 4 convolutional blocks ($4\!\times\!4$, progressively reduced stride) producing single-channel logit output (no sigmoid).

\subsubsection{Learning Mode}
In our experiments, the generator operates in \textbf{residual learning} mode: it predicts $\hat{n} = G(x_{\text{noisy}})$ and the clean image is obtained as:
\begin{equation}
\hat{x} = \text{clamp}(x_{\text{noisy}} - \hat{n},\; -1,\; 1)
\end{equation}
Predicted noise is additionally clamped to $\pm 0.6$ for stability.
